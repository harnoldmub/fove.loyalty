Boutique de démonstration

Site externe servi depuis une autre origine que FOVE. Le widget est ajouté avec une seule balise script.

Ouvrir avec ?key=fove_pk_test_…&app=http://localhost:5290.

const params = new URLSearchParams(location.search); const s = document.createElement("script"); s.src = (params.get("app") || "http://localhost:5290") + "/widget/fove-widget.js"; s.dataset.key = params.get("key") || ""; document.body.appendChild(s);
